From all those who want to see real progress in the gym, and not abstract one. I made a template to keep track of all my sessions and to see this in a graphic, I have designed this repository, so you can enter your gym sessions (folder: sesiones) and see the progress graphically of each exercise.

For using this repository, you just need:
1. Clone the repository on your computer.
2. Write "uv sync" to create the .env with all the dependencies needed.
